# E-Commerce Mobile App (Flutter)

A cross-platform mobile e-commerce client built with Flutter and BLoC state management.

> 🔗 **Backend Repository:** https://github.com/ahmedelsayedabdelkaream/ecommerce_backend

## Features
- **Authentication Screens:** Login and Sign Up UI integrated with JWT backend authentication.
- **Home & Product Catalog:** Reactive product list rendering.
- **Cart Management:** Real-time item additions, removals, and total price updates using BLoC.

## Tech Stack
- Flutter & Dart
- Flutter BLoC Pattern
- REST API Integration (HTTP/Dio)

## How to Run
1. `flutter pub get`
2. Configure API base URL in `lib/config/api_config.dart`
3. `flutter run`
